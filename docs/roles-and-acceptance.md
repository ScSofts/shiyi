# 《拾忆》四人分工与验收标准

> 项目：拾忆 —— 个人影像管理与智能检索平台
> 团队：像素合伙人（4 人）
> 周期：6 周　｜　交付：一个能真正跑起来的私人相册 Web 站

---

## 0. 一句话说清项目目标

**做一个能真正跑起来的私人相册 Web 站**：照片传上去以后，能按 **时间 / 人物 / 地点 / 内容描述** 四种方式找回来，还能整理成相册分享给别人。

四个卖点对应四句话：

| 卖点 | 用户怎么用 | 背后技术 |
|---|---|---|
| **和谁** | 点"人物"，看到"张三"的所有照片 | 人脸检测 + 512 维向量 + 归组 |
| **在哪里** | 点"地图"，点"杭州"，看到杭州拍的照片 | EXIF 提取经纬度 + 地图打点 |
| **拍过什么** | 搜"海边日落"，出相关照片 | Chinese-CLIP 图文向量 + 相似度检索 |
| **回顾生活** | 时间轴、往年今日、相册分享 | 拍摄时间排序 + 相册 + 分享链接 |

---

## 1. 最终交付物（W6 结束时必须全部有）

1. **一个 GitHub 仓库**：别人 `git clone` 下来，按 README 三条命令能跑起来
2. **一个能演示的网站**：本机或局域网访问，10 张以上真实照片能走完整个流程
3. **一份演示脚本**：照着念 8 分钟能演完（见本文 §6）
4. **答辩 PPT + 3 分钟录屏**（录屏是兜底：万一现场跑不起来还能放）
5. **五份文档**：README、接口契约、本分工文档、开发规范、测试报告

## 2. 分工总表（一句话版）

| 同学 | 角色 | 一句话职责 | 主战场目录 |
|---|---|---|---|
| **A** | 前端 · 上传与浏览 | 让照片"进得来、看得见" | `web/src/pages/Timeline.tsx`、`web/src/components/` |
| **B** | 前端 · 四种查找入口 | 让照片"找得着"：人物/地图/搜索/相册四个页面 | `web/src/pages/{People,Map,Search,Albums,Shared}.tsx` |
| **C** | 后端 · 数据地基 | 让照片"存得住"：数据库、登录、上传、缩略图、EXIF | `api/prisma/`、`api/src/routes/{auth,assets}.ts`、`api/src/lib/` |
| **D** | 后端 · 智能检索 | 让照片"能被搜到"：AI 服务 + 人物/搜索/地图接口 | `ai/`、`api/src/routes/{people,search,map}.ts` |

**为什么这样分**：两个人管"看得见的东西"，两个人管"存起来和搜得准的东西"。
每个人的文件互不重叠，只有三处是全组共用（见 §5）。

```
web/src/components/UploadDialog.tsx

```

**每周做什么**

| 周 | 任务 |
|---|---|
| W1 | 页面骨架、`PhotoGrid`、时间轴（先用假数据）、左侧导航 |
| W2 | 上传弹窗接真接口、大图查看器、加载中/空状态 |

**如果卡住**：时间轴先用假数据做完，不要等 C；上传接口没通就用 `data/` 里的假数据继续往下做。

### 同学 C —— 后端：数据地基

**你负责的东西**：数据库表结构、登录鉴权、上传接口、缩略图、拍摄时间和 GPS 提取。

**要写的文件**

```

api/src/routes/auth.ts         ← 登录 / 当前用户
api/src/routes/assets.ts       ← 上传 / 列表 / 详情 / 删除
api/src/lib/thumb.ts           ← sharp 生成 600px 缩略图
api/src/lib/exif.ts            ← exifr 读拍摄时间、经纬度、相机型号
api/src/lib/storage.ts         ← 文件存到 data/uploads/
api/src/middleware/auth.ts     ← JWT 校验
api/.env.example
```

**每周做什么**

| 周 | 任务 |
|---|---|
| W1 | `schema.prisma` 七张表、登录接口、**W1 第 3 天把 `docs/api-contract.md` 定稿发群里**、上传 + 缩略图 |
| W2 | 照片列表接口（按月分页）、详情、删除、EXIF 提取 |
| W3 | 相册/分享接口、错误码统一、越权检查 |
| W4 | 打 `docker compose` 或启动脚本、数据备份脚本 |
| W5 | 配合 A/B 联调，修接口问题 |
| W6 | 接口文档、部署说明、README |

**怎么算做完（验收标准）**

> 上传一张手机照片后，打开数据库能看到这条记录：**拍摄时间对、经纬度对、相机型号对、缩略图文件存在**，刷新网页数据还在。

**注意**：你是"别人的上游"。**W1 第 3 天必须把接口契约发出来**，否则 A/B/D 都在干等。

### 同学 D —— 后端：智能检索 + AI 服务

**你负责的东西**：整个 Python AI 服务、人物接口、搜索接口、地图接口。

**要写的文件**

```
ai/main.py               ← FastAPI，3 个接口：/embed /search /persons/*
ai/face.py               ← insightface 检测人脸 + 512 维向量
ai/clip.py               ← Chinese-CLIP 图片/文字向量
ai/person_match.py       ← 新人脸和已有人物比距离，归组（30 行）
ai/store.py              ← 向量存 memory + 落盘 JSON
ai/eval/queries.json     ← 50 条中文搜索词 + 期望结果，算准确率
api/src/routes/people.ts ← 人物列表 / 命名 / 合并 / 拆分
api/src/routes/search.ts ← 转发到 AI 服务
api/src/routes/map.ts    ← 有 GPS 的照片
api/src/routes/albums.ts ← 相册（简单 CRUD）
api/src/routes/share.ts  ← 分享链接
```

**每周做什么**

| 周 | 任务 |
|---|---|
| **W1** | **只干一件事：让 AI 服务对一张图输出"人脸框 + 人脸向量 + 图片向量"**（风险最高，必须最先验证） |
| W2 | 人物接口、人脸归组、命名 |
| W3 | CLIP 搜索接口、50 条评测集跑出准确率 |
| W4 | 合并/拆分、效果调优、地图接口、相册/分享接口 |
| W5 | 回归测试、准备演示数据（20 张照片 + 3 个人 + 3 个城市） |
| W6 | 测试报告、模型效果报告 |

**怎么算做完（验收标准）**

> 命令行调 `POST /embed` 传一张照片 → 返回"1 个脸 + 1 个 512 维向量 + 1 个图片向量"
> 调 `GET /search?q=海边日落` → 返回 20 个照片 id

**如果卡住（重要）**：装环境超过 3 天就立刻降级——
- 人脸：只做检测，不做自动分组（用户手动建人物）
- 搜索：改成"给每张图打固定标签，搜标签"
- 仓库里已经内置 **`MOCK_AI=1` 假数据模式**，整站不依赖真模型也能跑通演示

## 4. 全组共同遵守的 6 条

1. **接口先定**：`docs/api-contract.md` 是唯一依据。要改字段，先改这个文件并发群里，再改代码。
2. **只有三个文件是全组共用的**，别人要用可以，要改必须先说：
   - `api/prisma/schema.prisma` → 归 C
   - `ai/` 整个目录 → 归 D
   - `web/src/components/PhotoGrid.tsx` 和 `web/src/App.tsx` 路由表 → 归 A
3. **每天开工第一件事**：`git fetch && git rebase origin/main`
4. **分支不超过 3 天**，PR 当天开、48 小时内合并
5. **周五 30 分钟集成日**：全员拉最新代码，从"登录→上传→时间轴→人物→地图→搜索→相册→分享"走一遍，坏的当天修
6. **时间一律用 ISO 字符串**（`2026-11-17T10:00:00Z`），不要传时间戳数字

## 6. 答辩演示脚本（8 分钟，照着念）

| 步骤 | 操作 | 说的话 |
|---|---|---|
| 1 | 打开首页，展示时间轴 | "这是我们的时间轴，按拍摄时间自动分组" |
| 2 | 点上传，传 10 张照片 | "上传后系统自动提取拍摄时间、地点，并生成缩略图" |
| 3 | 回到时间轴，照片已出现 | "时间维度：按年月日组织" |
| 4 | 切到"人物" | "系统自动识别人脸并分组，这是识别出的 3 个人，我给其中一个命名'张三'" |
| 5 | 点张三 | "人物维度：这个人所有照片都在这里" |
| 6 | 切到"地图"，点杭州 | "地理维度：从地图上的城市进入，看到当时拍的照片" |
| 7 | 切到"搜索"，输入"海边日落" | "语义维度：不用记时间，直接描述内容就能找到" |
| 8 | 回到时间轴顶部"2023 年的今天" | "回顾：往年同一天的照片重新出现" |
| 9 | 建相册"毕业旅行"，生成分享链接 | "整理与分享：生成链接发给朋友" |
| 10 | 手机打开分享链接 | "无需登录即可查看" |
